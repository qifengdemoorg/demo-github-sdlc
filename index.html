Flow · 数据流闭环
05 / 10
05

数据流:一次迭代的闭环

01
OneTeam 的 PRD 经 GitHub MCP 同步为 Issue。
02
Issue 指派 Coding Agent,依 Spec 与指令文件写码、开 PR。
03
PR 触发 Code Review + Ruleset 门禁;Agentic WF 跑测试与诊断。
04
门禁通过,CI/CD 构建并 部署到 Azure。
05
Azure SRE 监控运行态,异常时 自愈 + 回写 Issue。
闭环第 5 步的运维事件回写为新 Issue → 回到第 1 步,需求—交付—运维持续循环。
